# Screenshots

Place screenshots here before submitting to Flathub.

## Required

- `main.png` — 1248×702px (16:9), showing the editor and live preview side by side

This file is referenced in `io.github.cave_nerd.LockJaw.metainfo.xml` and is required
for Flathub submission. The Flathub review team will reject the submission if it is missing
or the URL returns a 404.

## How to take a good screenshot

1. Run Lock Jaw with a vault containing some notes
2. Open a note with a mix of headings, lists, and code blocks so the preview looks populated
3. Resize the window to approximately 1248×702
4. Take a screenshot and save it as `main.png` in this directory
5. Commit and push to `main` before opening the Flathub PR
